Theames

Themes and mods for the Microsoft Teams desktop app, on Windows and macOS.

TLDR; Theames is a modloader for Teams. You use .theame files to add new mods and theames. You choose what's on from a Theames item inside Teams' own "..." menu.

Installing

Windows

  1. Unzip the download and run Theames.exe.
  2. Windows SmartScreen may warn you. Click More info, then Run anyway.
  3. On first run Theames adds a Theames shortcut to the Start menu and desktop and pins it to the taskbar. Open Teams from that shortcut from now on.

macOS

  1. Open the .dmg and drag Theames into Applications.
  2. Open Theames. On first launch it asks for the App Management permission (System Settings → Privacy & Security). That permission only lets Theames change the Teams icon, and you can skip it.
  3. That's it. Theames runs in the background and starts with your Mac, so from now on you just open Teams as usual.

Using themes

  1. Download a .theame file from the marketplace.
  2. In Teams, open the ... (Settings and more) menu and choose 🎨 Theames. Click Open themes folder and drop the file in.
  3. Select the parts you want. You can mix them across themes, for example a background from one theme with the chat style and mods of another. Changes apply straight away, with no restart.

What a theame can change

  • Backgrounds: an image, colour or gradient behind the whole Teams window
  • Chat styles: CSS for the chat and message area
  • Mods: JavaScript that changes how Teams looks and works. Several can be on at once
  • Icon: the app icon. On macOS this is the Teams icon itself; on Windows it is the Theames shortcut
  • Settings: colours, sliders and switches a theme exposes, which you adjust in the Theames panel

Want to make your own? The .theame format docs cover everything a theme can contain. Send finished ones to me@poplel.xyz to get them listed.

How it works

The new Teams draws its window in a Microsoft Edge WebView2. Theames starts Teams with WebView2's local debugging port switched on, connects to it over the Chrome DevTools Protocol on 127.0.0.1, and adds your selected theme parts to every Teams page. Theames has no window of its own. On macOS it stays running in the background and reconnects whenever Teams opens. On Windows it runs while Teams is open and quits when Teams does.

To remove it, use Uninstall Theames in the panel. That puts Teams back the way it was and keeps your downloaded themes.
