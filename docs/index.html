Theames — .theame format

The .theame format

Everything a theme file can contain, and how Theames uses it. Written for Theames 1.0.0.

TLDR; a .theame is a zip file with a manifest.json at its root. The manifest lists any mix of four kinds of parts: mods (JavaScript), backgrounds (an image or a CSS colour), chat styles (CSS) and an icon. It can also declare variables that users adjust in the Theames panel. People can mix parts from different themes, so each part should work on its own.

The archive

A theme is an ordinary zip archive renamed to .theame. manifest.json must sit at the root of the archive, not inside a folder. Every other path in the manifest is relative to that root. Any folder layout works. The built-in themes use this one:

MyTheme.theame
├── manifest.json
├── icon.png
├── bg/night.png
├── chats/bubbles.css
└── mods/tweaks.js

Users install a theme by putting the file in their themes folder. The panel's Open themes folder button opens it.

SystemThemes folder
macOS~/Library/Application Support/Theames/themes
Windows%APPDATA%\Theames\themes
Either$THEAMES_HOME/themes when the THEAMES_HOME environment variable is set

The file name identifies the theme. Theames saves the user's choices as File.theame::Part name and keeps variable values per file name. If you rename the file, users lose their selection and settings for it. Keep the name the same across versions and put the version in the manifest.

manifest.json

{
  "name": "Night Shift",
  "version": "1.2.0",
  "author": "you",
  "description": "Dark blue panels and neon chat bubbles in an accent colour you pick.",
  "preview": "preview.png",
  "icon": "icon.png",
  "variables": [
    { "name": "accent", "label": "Accent", "type": "color", "default": "#33ff88" }
  ],
  "backgrounds": [
    { "name": "Night city", "file": "bg/night.png" },
    { "name": "Plain",      "color": "linear-gradient(#101820, #000)" }
  ],
  "chats": [
    { "name": "Neon bubbles", "file": "chats/bubbles.css" }
  ],
  "mods": [
    { "name": "Compact sidebar", "entry": "mods/tweaks.js" }
  ]
}
FieldTypeRequiredMeaning
namestringyesDisplay name in the panel and the marketplace.
versionstringnoYour version, e.g. "1.2.0". Shown, not compared.
authorstringnoShown in the marketplace.
descriptionstringnoMarketplace only. A short summary of the theme. See Marketplace listing.
previewstring or arraynoMarketplace only. Path to a preview image, or a list of paths. See Marketplace listing.
modsarraynoJavaScript parts. See Mods.
backgroundsarraynoBackground parts. See Backgrounds.
chatsarraynoChat-area CSS parts. See Chat styles.
iconstringnoPath to an icon image. See Icon.
variablesarraynoUser settings. See Variables.

A theme can include any subset of these. Part names are how Theames refers to a part, so keep them unique within each list and don't rename them between versions. Theames ignores fields it doesn't know.

Mods

"mods": [ { "name": "Compact sidebar", "entry": "mods/tweaks.js" } ]

A mod is a JavaScript file that runs inside Teams. Users can turn on any number of mods at once, from any themes. Theames runs the file in the global scope of every Teams page. It runs when the mod is switched on, and again each time a Teams page loads.

Mods can be switched off without restarting Teams. To make that possible, Theames records what a mod creates while its file is running, and removes exactly those things when the mod is switched off:

  • elements added to the page during that first run,
  • MutationObservers created during it (they are disconnected),
  • setInterval and setTimeout timers started during it (they are cleared).

Event listeners, and elements or timers created later from inside a callback, are not tracked. Write mods so they still undo cleanly:

  • Wrap the file in an IIFE. Top-level const/let would clash when the mod is switched off and on again.
  • Add your <style> element right away, in the first run, so it gets removed with the mod.
  • Make later changes inert without that style. For example, mark Teams elements with a data- attribute and target the attribute from your CSS. Once the style is gone, the attribute does nothing.
  • Create observers and timers at the top level of the file, not lazily, so they are tracked.
(function () {
  var ID = 'my-compact-sidebar';
  if (document.getElementById(ID)) return;          // already applied on this page

  var style = document.createElement('style');
  style.id = ID;
  style.textContent = '[data-my-compact] { padding: 2px !important; }';
  document.head.appendChild(style);                 // tracked: removed on switch-off

  function tag() {
    document.querySelectorAll('[data-tid="chat-pane-message"]').forEach(function (n) {
      n.setAttribute('data-my-compact', '');         // inert once the style is gone
    });
  }
  tag();
  new MutationObserver(tag).observe(document.body, { childList: true, subtree: true }); // tracked
})();

Teams' class names are generated and change between updates. Target the data-tid attributes instead, which are much more stable. If a mod has variables and the user changes one, Theames switches the mod off and on again with the new values. For older mods, the selected background image is also available as window.imageBase64Background (a data URI, or an empty string).

Backgrounds

"backgrounds": [
  { "name": "Night city", "file": "bg/night.png" },
  { "name": "Solid",      "color": "{{background}}", "transparent": true },
  { "name": "Keep Teams", "file": "bg/soft.jpg", "transparent": false }
]
FieldMeaning
nameRequired. Shown in the panel.
fileAn image in the archive: .png, .jpg/.jpeg, .gif, .webp or .svg.
colorInstead of file: any CSS background value, such as a colour or a gradient. Variables work here.
transparentDefault true. Clears Teams' own opaque panels so the background shows through the whole window. Set false to keep them.

One background is active at a time. The image is embedded into each Teams page, so keep files reasonably small: a compressed JPEG or WebP at screen size is plenty.

Chat styles

"chats": [ { "name": "Neon bubbles", "file": "chats/bubbles.css" } ]

A chat style is a CSS file for the chat and message area. One is active at a time, separate from the background. Variables are filled in before it is applied. Teams sets many styles inline, so you will usually need !important:

[data-tid="chat-pane-message"] {
  background: {{accent}} !important;
  border-radius: 14px !important;
}

Icon

"icon": "icon.png"

An image the user can pick as their app icon. A square PNG works best (512 × 512 or larger).

  • macOS: it becomes the Microsoft Teams app icon in the Dock and Finder. This needs the App Management permission, and Theames applies it again after a Teams update replaces the app.
  • Windows: Teams' own icon can't be changed, so it becomes the icon of the Theames shortcut (Start menu, desktop and the pinned taskbar shortcut).

Variables

Variables let users adjust a theme without editing it. Theames shows a control for each one in the panel and saves the user's values in its own settings. The .theame file itself is never changed.

"variables": [
  { "name": "accent", "label": "Accent",        "type": "color",  "default": "#33ff88" },
  { "name": "size",   "label": "Text size (px)", "type": "range",  "min": 10, "max": 15, "step": 1, "default": "12" },
  { "name": "tint",   "label": "Tint emojis",   "type": "toggle", "default": "0" }
]
FieldMeaning
nameRequired. The name used in placeholders.
labelText shown next to the control. Defaults to the name.
typecolor (colour picker, the default), range (slider) or toggle (checkbox, value 1 or 0).
defaultRequired, and always a string, even for numbers: "12", not 12.
min, max, stepNumbers for a range slider.

Placeholders are replaced in mod JavaScript, chat CSS and background color values. They are not replaced inside image files.

WriteBecomes
{{accent}}The value, e.g. #33ff88.
{{accent|rgb}}A hex colour as r, g, b, e.g. 51, 255, 136. Useful in rgba({{accent|rgb}}, 0.5).
{{#tint}}…{{/tint}}Kept only when the variable is on.
{{^tint}}…{{/tint}}Kept only when the variable is off.

A value counts as off when it is empty, 0, false, off or no. Blocks for different variables can be nested. An unknown name in a block counts as off. An unknown plain placeholder is left as written. Variables belong to their own theme, so two themes can both have an accent without clashing.

Marketplace listing

Two manifest fields exist only for the marketplace. The Theames app doesn't use them, so adding them doesn't change how your theme works and doesn't need a newer version of Theames. The marketplace reads them straight out of the .theame archive, so updating the file updates the listing.

"description": "Drifting aurora colours behind Teams, with frosted-glass chat bubbles.",
"preview": ["previews/chat.png", "previews/channels.png"]
FieldMeaning
descriptionOne to three sentences saying what the theme does and what users can adjust. Plain text, around 300 characters at most. It is also searchable on the marketplace.
previewAn image in the archive (.png, .jpg, .webp or .gif), or a list of up to six. The first is shown on the theme's card, and people can switch between the others. Clicking a preview opens it full size.
  • Use a 16:10 screenshot, e.g. 1280 × 800. Cards crop other shapes from the top-left corner.
  • Keep each image small, ideally under 300 KB (a compressed JPEG or WebP). People download the whole .theame, previews included.
  • Show only your theme, with no other mods on, so people see what they will get.
  • Check your screenshot for private information: names, messages, meeting titles and profile pictures. Use a test account or a demo team if you can.

Packing & testing

Zip the contents of your theme folder, not the folder itself, then give it a .theame name.

macOS / Linux

cd my-theme
zip -r -X ../MyTheme.theame . -x '.DS_Store'

Windows (PowerShell)

Compress-Archive -Path .\my-theme\* -DestinationPath .\MyTheme.zip
Rename-Item .\MyTheme.zip MyTheme.theame

Python (any system)

import os, zipfile
src = "my-theme"
with zipfile.ZipFile("MyTheme.theame", "w", zipfile.ZIP_DEFLATED) as z:
    for base, _, files in os.walk(src):
        for f in files:
            if f != ".DS_Store":
                full = os.path.join(base, f)
                z.write(full, os.path.relpath(full, src))

Check the result with unzip -l MyTheme.theame: manifest.json should be listed with no folder in front of it.

Testing

  1. Copy the file into your themes folder and open the Theames panel in Teams. A theme with a broken archive or invalid manifest.json won't show up. Check the JSON for trailing commas and numbers written without quotes in default.
  2. Switch each part on and off. After switching off, Teams should look exactly as it did before.
  3. To see errors, open chrome://inspect in Chrome or Edge while Theames is running, add localhost:9222 under Configure…, and inspect the Teams page. Mod errors appear in the console as [theames] mod … failed.
